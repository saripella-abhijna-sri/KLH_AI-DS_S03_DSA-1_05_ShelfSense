ABSTRACT:
ShelfSense: Library Circulation is a library management project designed to simplify and improve the process of issuing and returning books in a campus library. The system focuses on efficiently managing book records, tracking book availability, monitoring issue and return dates, and calculating the number of books currently issued. It aims to provide quick and accurate information about whether a particular book is available on the shelf, reducing manual effort and saving time for both students and library staff.The project implements various fundamental Data Structures and Algorithms concepts, including hashing and counting, recursion, difference arrays, string matching using the KMP algorithm, binary search, and queues. These techniques are applied to solve different library-related operations efficiently. The system also compares brute-force and optimized approaches to understand algorithm performance and time complexity using Big-O notation.
Synthetic datasets are used to test the system under different scenarios, ensuring consistent and reliable results. The project includes automated test cases, performance measurements, and demonstrations to evaluate the correctness and efficiency of each algorithm.Overall, ShelfSense demonstrates how Data Structures and Algorithms can be applied to real-world campus services to develop a faster, more organized, and reliable library circulation system. It also provides a foundation for future enhancements such as overdue book tracking, reservation management, and multi-counter return processing.
